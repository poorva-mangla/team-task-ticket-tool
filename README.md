# TeamFlow – Team Task Ticket Tracker

TeamFlow is a task and ticket management website that helps teams track daily work, reuse existing tickets, and maintain work history across team members.

## Features

- **Dashboard:** Overview of tasks, tickets, rework, and team members.
- **Daily Tasks:** Add, search, filter, and delete tasks.
- **Ticket Management:** Create tickets and add work to existing tickets.
- **Work History:** Track contributions and changes made by different team members.
- **Rework Tracking:** Count fixes and repeated work.
- **Local Storage:** Save data in the browser.
- **Responsive Design:** Supports desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

The project will open in your browser.

**Note:** This is a frontend-only project. Data is stored in browser LocalStorage and is not shared across devices or users.
